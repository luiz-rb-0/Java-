# ☕ Estudos de Java

Repositório com exercícios e pequenos projetos desenvolvidos durante meus estudos de Java.

## Conteúdos praticados

Os arquivos presentes neste repositório incluem exercícios de lógica e programação envolvendo conceitos como:

- Entrada e saída de dados
- Variáveis e tipos de dados
- Estruturas condicionais
- Operadores
- Estruturas de repetição
- Organização de classes e pacotes

## Estrutura

A pasta `primeiroProjeto` reúne exercícios como `Condicional.java`, `Lista2.java`, `Lista4.java` e `Primeira.java`, além da estrutura de projeto utilizada durante as aulas.

## Objetivo

Registrar a evolução dos estudos em Java e manter os exercícios organizados em um único repositório de referência.

## Como executar

Os arquivos podem ser executados em uma IDE Java ou pelo terminal utilizando o JDK.
